# 💫 About Me
🎓 Final-year Business Information Technology student at HAMK (Häme University of Applied Sciences), specialising in **cybersecurity**<br><br>
🎓 Published bachelor's thesis auditing AWS misconfigurations with Prowler & ScoutSuite against the CIS AWS Foundations Benchmark — including a finding that ScoutSuite silently fails EC2 enumeration under restricted credentials (missing `ec2:DescribeRegions`), returning a clean-looking report while real vulnerabilities go undetected. [Read the thesis](https://www.theseus.fi/handle/10024/924411)<br><br>
🛠️ Hands-on with penetration testing, OSINT, and cloud security — from exploiting Metasploitable boxes to passive recon and social engineering analysis. Infrastructure-as-code (Terraform), Kubernetes, Azure and GCP practised through coursework and assignments<br><br>

🐞 Bug bounty and vulnerability research on [HackerOne](https://hackerone.com/ilyas_oub) and [Bugcrowd](https://bugcrowd.com/ilyasoux93c5c3) — reporting issues in web platforms, fintech SDKs and enterprise endpoint software, mostly through static analysis and reverse engineering of released packages and binaries. Classes of issue include authentication bypass, hard-coded cryptographic keys and command injection. Details are withheld in line with programme disclosure policies<br><br>
🧩 Open-source contributor to **LibreOffice core** (C++) — merged patches replacing `#include` guards with `#pragma once` in the `comphelper` module ([tdf#143148](https://bugs.documentfoundation.org/show_bug.cgi?id=143148), [Gerrit 203432](https://gerrit.libreoffice.org/c/core/+/203432)) and modernising lookups to C++20 `contains()` ([tdf#158237](https://bugs.documentfoundation.org/show_bug.cgi?id=158237), [Gerrit 198893](https://gerrit.libreoffice.org/c/core/+/198893))<br><br>
🌍 Trilingual: Arabic (native), English (C1), French (C1)<br><br>
📫 Available for a cybersecurity internship (pentesting, cloud security, GRC) as soon as possible
